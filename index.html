FZT Portal · Mockup, alle Zahlen sind Beispieldaten

Ein Portal statt sechs Adressen

Reports, Maintenance, Metrics, Smart Booking und die M&B/Performance-Rechner werden zu einem Frontend mit gemeinsamem Login, gemeinsamer Navigation und einem Designsystem. Nextcloud und FlightOffice 24 bleiben eigenständig und werden verlinkt. Die Backends bleiben zunächst bestehen und liefern nur noch Daten.

Prinzipien

  • Ein Login über das bestehende Keycloak, Rollen Pilot, Fluglehrer, Technik, Büro.
  • Startseite zeigt, was heute zählt: Wetter, eigene Flüge, Flottenstatus, fällige Punkte.
  • Jede Ansicht funktioniert am Handy ohne zweites Layout: Seitenleiste wird zur Tab-Leiste.
  • Zustand wird sichtbar codiert: grün flugklar, gelb fällig, rot gesperrt oder Werft.
  • Kennzeichen, Stunden und METAR immer in Monospace, damit Zahlen untereinander stehen.

Technik-Vorschlag, Endausbau

  • Frontend: React 19, TypeScript, Vite, TanStack Router und Query, Tailwind, shadcn/ui. PWA mit Web Push und Kamera.
  • Backend: Node mit Fastify, OpenAPI aus zod, ein Vertrag für beide Seiten. PostgreSQL mit Drizzle, Jobs mit pg-boss.
  • Motordaten: Python-Dienst mit pandas, per HTTP angebunden, übernimmt den bestehenden Analyzer.
  • Login: Keycloak, OIDC mit PKCE, Rollen Pilot, Fluglehrer, Technik, Büro.
  • Dateien: Cloudflare R2 für Dokumente, Mangelfotos, PDF. Nextcloud bleibt für Vereinsdokumente.
  • Hosting: Docker Compose auf einem Hetzner-Server, Caddy, Cloudflare davor. GitHub Actions, Sentry, nächtliches Backup nach R2.

Bewusst nicht: Next.js oder Server-Rendering hinter Login, Cloudflare Workers plus D1 als Hauptplattform, eigener Login. Ist das Team in .NET oder Python im Backend stärker, bleibt der API-Vertrag gleich und nur das Backend wechselt die Sprache.

Reihenfolge

  • 1. Shell, Login, Startseite, Flotte, Links zu Cloud und FlightOffice 24.
  • 2. Reports übernehmen: Piloten, Flugzeuge, Schule, Fluglehrer, Segelflug.
  • 3. Motordaten übernehmen, Uploads und Flugliste mit Kurven.
  • 4. M&B und Performance als Module mit gespeicherten Kennzeichen-Daten.
  • 5. Smart Booking produktiv, Wartung integriert, Werkstattrotation.
